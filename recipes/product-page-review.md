# Product page review recipe

1. Locate the product template and runtime product-data source.
2. Check title, primary image alt text, price source, availability source, variant controls, add-to-cart semantics, shipping/returns references, and structured data.
3. Mark unsupported product facts as `UNKNOWN`.
4. Separate code defects from missing merchant data.
5. Recommend the smallest safe patch and a concrete verification step.
