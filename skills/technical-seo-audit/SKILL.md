# Technical SEO Audit

Use for product, collection, category, blog, or template-level SEO review.

## Required checks
- title and meta description source;
- canonical behavior;
- robots/indexability;
- one meaningful H1;
- crawlable internal links;
- pagination/filter parameter behavior where visible in code;
- duplicate template outputs;
- structured data consistency.

Distinguish code evidence from SEO strategy inference. Do not claim rankings, traffic, search volume, or indexing status without external verified data.
